# Design - Repay M03 视觉与交互规范

本文件基于 ios_design.md（iOS 毛玻璃风格设计系统）落地，严格遵循其设计令牌，不另立主观风格。所有页面以本文件为准，与 Ant Design Vue 默认样式冲突时以此为准。

---

## 一、设计基调：iOS 毛玻璃 · 轻盈留白

整体追求 iOS 系统原生质感：半透明毛玻璃面板悬浮于柔和渐变背景之上，内容紧凑但不拥挤，留白用于呼吸而非填充。核心词：通透、层次、温度。

- 不使用深色工具风、不使用硬边框分割区域
- 结构边界一律靠「背景色阶 + 毛玻璃模糊」区分，禁止 1px 实线
- 圆角偏大（16~20px），阴影柔和、低透明度
- 所有交互响应轻快，配合微动效

## 三、字体与排版

- 字体族：-apple-system, 'SF Pro Text', 'PingFang SC', 'Helvetica Neue', sans-serif
- 字号体系（紧凑）：

| 令牌 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| --fs-display | 30px | 1.15 | 700 | 核心大数字（总额/剩余） |
| --fs-title | 17px | 1.3 | 600 | 卡片标题、区块标题 |
| --fs-body | 15px | 1.5 | 400 | 正文、列表内容 |
| --fs-meta | 13px | 1.4 | 400 | 次级信息、记录人、日期 |
| --fs-label | 12px | 1.2 | 500 | 标签、徽标（letter-spacing 0.02em） |

- 字间距统一为 0，不做负字距。
- 数字使用等宽数字特性 font-variant-numeric: tabular-nums，金额对齐不跳动。

## 四、间距与布局（紧凑）

8px 基准，整体比常规记账软件更紧凑，减少空旷感：

| 令牌 | 值 | 用途 |
|------|----|------|
| --sp-1 | 4px | 图标与文字间距 |
| --sp-2 | 8px | 标签内距、紧凑元素间距 |
| --sp-3 | 12px | 卡片内元素间距 |
| --sp-4 | 16px | 卡片内边距、区块间距 |
| --sp-5 | 20px | 卡片间距、列表行间距 |
| --sp-6 | 28px | 大区块间距 |

### 布局原则

- 概览区：4 个统计卡 + 进度条横向并排，一行内紧凑铺满，不单独占整屏。
- 统计卡：内边距 16px，数字 30px，标签 12px，卡片高度约 96px，紧凑。
- 进度条：高度 10px，胶囊形，带内发光，紧贴统计卡下方。
- 列表区：按月分组，月标题行高 32px，记录行高约 64px，行间距 8px。
- 整体最大宽度 960px 居中，桌面不铺满，保留两侧呼吸；移动端撑满。
- 页面内边距：桌面 24px，移动端 16px。

## 五、毛玻璃面板

所有承载内容的容器统一为毛玻璃面板：

    .glass {
      background: var(--glass);
      backdrop-filter: blur(20px) saturate(160%);
      -webkit-backdrop-filter: blur(20px) saturate(160%);
      border: 1px solid var(--glass-border);
      border-radius: 18px;
      box-shadow: 0 1px 2px rgba(0,0,0,0.04), 0 8px 24px rgba(0,0,0,0.06);
    }

- 普通面板用 --glass，模态/弹层用 --glass-strong。
- 嵌套面板：内层面板背景透明度略高，不额外加边框，靠层次区分。
- 背景渐变固定铺满 body，面板悬浮其上产生透色效果。

## 六、组件规范

### 按钮

- 主按钮：--accent 实色底，白字，圆角 12px，内距 10px 18px，hover 轻微提亮。
- 次按钮：透明底，--ink 字，hover 出现 --accent-soft 底色。
- 图标按钮：36×36px 圆角 10px，hover --accent-soft。
- 过渡 transition: all 180ms cubic-bezier(0.4,0,0.2,1)。

### 输入框

- 透明底（继承面板），--glass-border 描边 1px，圆角 12px，内距 10px 14px。
- 聚焦时描边变 --accent，附 3px --accent-soft 外发光。
- 占位符 --ink-faint。

### 标签 / 徽标

- 快捷词标签：--accent-soft 底，--accent 字，圆角 9999px，内距 4px 10px，点选即填。
- 「历史」标记：--warn-soft 底，--warn 字。

### 统计卡

- 毛玻璃面板，内边距 16px。
- 顶部 12px 标签（--ink-soft），下方 30px 大数字。
- 已还卡数字 --success，剩余卡数字 --warn，其余 --ink。
- 数字加载时 count-up 动画。

### 进度条

- 轨道：rgba(0,0,0,0.05)，高 10px，圆角 9999px。
- 填充：--accent 渐变到 --success，圆角 9999px。
- 内发光呼吸动画（见动效章节）。
- 上方一行：左「还款进度」标签，右百分比 + 剩余金额。
- 下方一行：起始提示与「还清即结束」。

### 明细行

- 毛玻璃面板单行，高约 64px，内边距 12px 16px。
- 布局：左日期+备注（上下两行），右金额（大）+记录人（小）。
- 新增行：左侧 3px --accent 条滑入，2 秒后淡出。
- 操作按钮（编辑/删除）：默认隐藏，hover 行时右侧淡入显示。

### 月分组标题

- 行高 32px，左「2026-03」，右「合计 ¥6,000」，--ink-soft 13px。
- 下方接明细行，组间距 --sp-5。

## 七、动效设计（仪式感 + 轻快）

所有动效须包裹 @media (prefers-reduced-motion: reduce) 降级。

### 1. 登录页扫描入场
- 毛玻璃面板从下方 translateY(20px) -> 0 淡入，300ms。
- 一道高光横线从面板顶部扫过（linear-gradient + translateX），800ms 一次。

### 2. 数字 count-up
- 统计卡数字从 0 滚动到目标值，800ms，ease-out-cubic。
- 进入视口时触发（IntersectionObserver），不一次性全滚。

### 3. 进度条呼吸发光
- 填充条 box-shadow 在 0 0 6px rgba(10,132,255,0.25) 与 0 0 14px rgba(52,199,89,0.45) 之间循环，3s 一周期。

### 4. 列表行入场
- 新增记录从顶部 translateY(-12px) + opacity:0 滑入，200ms。
- 删除记录 opacity:0 + translateX(12px) 淡出，200ms，高度随后收缩。

### 5. 里程碑庆祝
- 节点：25%、50%、75%、剩余小于1万、100% 还清。
- 触发：全屏 --gold 文字弹出（scale(0.6)->1，500ms）。
- 100% 还清时撒金色粒子（60 个，cubic-bezier(0.2,0.7,0.3,1) 抛物线），3 秒。
- 其余节点仅文字弹现，2 秒。

### 6. 按钮与行 hover
- 按钮 hover：transform: translateY(-1px)，阴影加深，180ms。
- 明细行 hover：背景透明度提升至 0.75，操作按钮淡入。

### 7. 模态弹层
- 遮罩 rgba(0,0,0,0.3) + backdrop-filter: blur(8px)。
- 面板 scale(0.95)->1 + opacity:0->1，200ms cubic-bezier(0.4,0,0.2,1)。

### 8. 背景微动
- 页面背景渐变在 20s 内缓慢偏移 background-position，营造光感流动，极弱。
### 8.1 背景装饰光斑
在渐变背景之上叠加三枚模糊光斑（蓝、橙、紫），为毛玻璃面板提供折射底色，增强通透层次感：
- 光斑 1（蓝 rgba(10,132,255,0.22)）：右上角，420px，blur(80px)，22s 浮动
- 光斑 2（橙 rgba(255,149,0,0.16)）：左下角，360px，blur(80px)，26s 浮动
- 光斑 3（紫 rgba(175,82,222,0.18)）：中部，300px，blur(70px)，30s 浮动
- 三枚光斑各自缓慢位移+缩放，互不同步，形成活的背景
- 前两枚用 body::before/::after，第三枚用 .bg-orb-3 元素（挂在 App.vue）
- prefers-reduced-motion 下隐藏所有光斑
- 页面背景渐变在 20s 内缓慢偏移 background-position，叠加光斑营造光感流动

## 八、与 Ant Design Vue 的协调

- AntDV 组件默认样式以此规范覆盖：圆角、配色、阴影、字体均按上文令牌。
- 按钮、输入框、Modal、表格等组件通过全局 CSS 变量 + 组件级 :deep() 覆盖。
- 不引入 AntDV 暗色主题。
- 图标使用 AntDV 内置 @ant-design/icons-vue，尺寸 16/20px。

## 九、响应式

- 桌面（>=768px）：统计卡 4 列，列表单列，最大宽 960px 居中。
- 移动（<768px）：统计卡 2 列，进度条全宽，列表全宽，页面内边距 16px。
- 模态移动端宽度 92vw。

---

## 十、不要做的事

- 不用深色工具风、不用 Adobe 红、不用硬边框分割。
- 不用高透明度黑色阴影（避免 Windows 感）。
- 不让任何区域大面积留白空旷，紧凑为先。
- 不用超过两种动效同时强干扰阅读。
- 不用纯白不透明面板堆叠（失去毛玻璃通透感）。
